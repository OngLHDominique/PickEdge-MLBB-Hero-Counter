# PickEdge-MLBB-Hero-Counter
<p>
  PickEdge - MLBB Hero Counter is a counter-pick tool for a game called Mobile Legends: Bang Bang.
  The goal is to allow players to utilise this during the ban-pick phase which is time sensitive, deciding which hero counters the enemy's picks is half strategy, half guesswork. PickEdge will eliminate the required guesswork and massively reduce the time wasted while trying to decide the best hero counter. This would be useful in the ban-pick phase and allow players to quickly and confidently decide the best pick based on the enemy team composition and their hero counters.
</p>

<p>
  The objective is to enable new players that are currently learning the game to be able to have fun and learn at the same time without stress.
</p>

<p>
  PickEdge can be utilised on a variety of mobile devices and website!
</p>
